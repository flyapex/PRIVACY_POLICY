Privacy Policy

YouTube Thumbnail Grabber — Last updated: June 27, 2026

Overview

YouTube Thumbnail Grabber does not collect, transmit, or share any personal data. The extension operates entirely within your browser to fulfill its single purpose: downloading YouTube video thumbnails.

Data Storage

All data is stored locally in your browser using chrome.storage.local and chrome.storage.sync.

Data Storage Location Purpose Retention
Download history (video IDs, filenames, timestamps) chrome.storage.local Display recent downloads in the side panel Max 50 entries, auto-pruned
Download count chrome.storage.local Badge counter on the extension icon Until user resets
Extension enabled/disabled state chrome.storage.sync Persist user preference across devices Until user changes
Theme preference chrome.storage.local Remember light/dark mode choice Until user changes

Network Requests

The extension makes outbound requests only when you explicitly trigger an action:

Destination When It Happens What Is Sent
https://img.youtube.com/vi/{videoId}/{quality}.jpg You click a download button or right-click → download The YouTube video ID extracted from the page URL
https://www.youtube.com/* You visit YouTube (content script runs) None — reads the page DOM to detect video links

No data is sent to any analytics service, tracking endpoint, third-party server, or the extension developer.

Data Sharing

  • No personal information is collected
  • No data is sold to third parties
  • No data is transferred for purposes unrelated to the extension's single purpose
  • No data is used to determine creditworthiness or for lending purposes

Third-Party Services

The extension does not integrate any third-party analytics, crash reporting, or advertising SDKs.

Children's Privacy

This extension does not knowingly collect any personal information from children under the age of 13. If you believe a child has provided personal data, please contact us and we will delete it.

Changes to This Policy

If this policy changes, the version number in the extension's manifest will be updated and you will be notified through the Chrome Web Store update mechanism.
